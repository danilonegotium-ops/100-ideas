# Balkan Recipe API — SPEC

**MVP:** A dev-facing JSON API, not a UI. `GET /api/recipes` (implemented as a plain Node.js Vercel serverless function at `api/recipes.js` — no framework, per the sprint's "top-level `/api/*.js` = zero-config Node function" convention) returns the full curated dataset of 15 traditional Balkan recipes, or a filtered subset via `?name=` (case-insensitive substring match against id/name/altNames) and/or `?tag=` (case-insensitive exact match against the tags array). Both params can be combined. CORS is open (`Access-Control-Allow-Origin: *`) so the API is directly callable from browser JS. `index.html` is API documentation (endpoint, params table, example curl, example response, available tags) rather than an interactive tool, plus a small "try it live" widget that calls the real endpoint from the browser (only functional once deployed to Vercel — a plain static file server has no `/api` route, and the widget shows a clear message in that case rather than failing silently).

**Out of scope for this pass:** pagination (15 recipes is small enough that the full list/filtered list is always returned in one response), rate limiting / API keys (matches the "free, keyless" framing used elsewhere in Wave 2), a recipe-detail-by-slug route like `/api/recipes/sarma` (the `?name=` filter covers the same need for this MVP), write endpoints (this is a read-only reference dataset).

**Data:** 15 original recipe write-ups in `api/recipes-data.json` (Sarma, Ćevapi, Ajvar, Pljeskavica, Burek, Gibanica, Karađorđeva Šnicla, Prebranac, Musaka, Punjene Paprike, Đuveč, Pasulj, Šopska Salata, Palačinke, Kremšnita) — ingredients and steps are the author's own concise write-ups of standard, well-known preparations for each dish, not copied from any single source. Nutrition figures (`nutritionPerServing`) are reasonable estimates for planning purposes based on typical composition of each dish, explicitly labeled as estimates via a `note` field on every entry — not lab-measured or medical-grade values, and not a substitute for professional nutrition advice.
