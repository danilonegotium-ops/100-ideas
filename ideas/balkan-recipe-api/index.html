Balkan Recipe API

A free JSON API for developers: 15 traditional Balkan recipes with ingredients, steps, and estimated nutrition. No auth, no key, just GET.

Endpoint

GET /api/recipes

Returns JSON. CORS is open (Access-Control-Allow-Origin: *) so you can call it directly from a browser.

Query parameters

ParamTypeDescription
name string Case-insensitive substring match against the recipe's id, name, or alternate names. e.g. ?name=sarma
tag string Case-insensitive exact match against one of the recipe's tags. e.g. ?tag=stew

Both params can be combined (AND). Omit both to get all 15 recipes.

Available tags: stew, grill, meat, condiment, vegetarian, vegan, pastry, breakfast, fried, festive, bake, salad, summer, winter, dessert

Example request

curl "https://balkan-recipe-api.vercel.app/api/recipes?name=sarma"
