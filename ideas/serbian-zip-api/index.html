Serbian ZIP Codes API

A fast, free API for developers to get data about cities, municipalities, and postal codes in Serbia. No API key, no signup, no rate limit headaches.

GET /api/zip

Query parameters

ParamTypeDescription
code string Exact postal code lookup, e.g. 11000. Takes priority over city if both are sent.
city string Case-insensitive partial match against place name, e.g. novi sad.
limit integer Max results to return. Default 50 with no query, 200 otherwise. Capped at 200.

No params: returns a 50-record sample so you can see the shape of the data.

Example — lookup by postal code

curl "https://serbian-zip-api.vercel.app/api/zip?code=11000"

Example — search by city name

curl "https://serbian-zip-api.vercel.app/api/zip?city=novi%20sad"

Notes

  • 1,155 postal code records covering Serbia, sourced from GeoNames' public bulk export.
  • Some place names (like Novi Sad) are listed under a more specific modern postal code in GeoNames' data rather than the historic "round number" code — e.g. Novi Sad is 21102, not 21000, in this dataset. Use ?city= if an exact code lookup comes up empty.
  • Data is static, baked into this deployment at build time — no runtime dependency on GeoNames, so no downtime risk from their servers and no rate limit on this API.
  • CORS is open (Access-Control-Allow-Origin: *) so you can call this directly from a browser.
