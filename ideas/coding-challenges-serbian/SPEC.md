# Programerski izazovi na srpskom (Coding Challenges in Serbian) — SPEC

**MVP:** 15 real beginner-level programming challenges, entirely in Serbian (Latin script) — prompts, code snippets' surrounding explanations, and grading feedback are all Serbian; code snippets themselves are plain JavaScript (`"šta ispisuje ovaj kod"` / `"koji je rezultat"` style), chosen because it needs no compiler or type-system explanation for a beginner. Covers four beginner topics with 3-5 questions each: promenljive (variables), uslovi (conditionals), petlje (loops), funkcije (functions). Each question is either multiple-choice or fill-in-the-blank; answering gives instant feedback (correct/incorrect styling, the right answer if wrong, and a short Serbian explanation) before the user moves to the next question with an explicit "Sledeće pitanje" button so they have time to read the explanation. A running score is shown throughout, and a summary screen at the end shows the final score, percentage, and an encouragement message. "Pokušaj ponovo" resets and replays the same 15 questions from the start.

**Out of scope for this pass (scope note from MASTER_TRACKER.md):** real code execution — there's no safe way to run arbitrary user-submitted code client-side in a weekend-scope static site (no sandboxed judge/worker infrastructure), so this ships as multiple-choice/fill-in-the-blank grading a fixed set of known-good answers, not a LeetCode-style code editor + test runner. Also out of scope: a persistent per-user score history across visits (score resets on reload/restart — no `localStorage` used here since each attempt is meant to be a fresh, replayable practice run); randomized question order or a larger question bank (fixed 15 questions in a deliberate beginner-friendly order: variables before conditionals before loops before functions).

**Data/content:** all 15 questions were hand-written for this project in `data.js` (not sourced from an external question bank), covering genuinely correct JavaScript beginner concepts — every multiple-choice `correctIndex` and every fill-in-the-blank accepted answer was verified against real JavaScript semantics (see the Node test run during development, which asserts every question's own listed correct answer actually passes its own grading function).
